    The documents it is reading

    three invented manuals

      Nothing is written to disk. A document you add lives in memory and is gone when this stops — an upload folder on somebody else’s machine is a place to put things that should not be there. A PDF is read for the text it already carries; a scan has none, and says so.

      Adding a document rebuilds the whole index, not only its own part. A document is found by names worked out against the whole corpus — an ordinary word only becomes a name if it appears nowhere else — so a fourth document can take a name away from the second, and it should.
